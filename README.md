Nookie

Nookie is an iOS app designed to help students discover, save, and share their favorite study spots, including cafés, libraries, and other cozy spaces.
The app makes finding the perfect place to study easier through community-contributed information about seating availability, noise levels, outlets, accessibility, and more.

Key Features

Explore Study Spots: Discover nearby cafés, libraries, and study spaces using Apple Maps.
Community Contributions: Share information about seating, outlets, noise levels, food policies, and accessibility.
Live Seat Reports: Submit real-time updates about how crowded a location is.
Save Favorites: Bookmark study spots for easy access later.
Personalized Avatars: Customize your character for a more playful and cozy experience.
Community Database: View shared information from other users to make informed decisions.

Tech Stack

SwiftUI — iOS interface and app development
MapKit — Location search and interactive maps
Firebase Authentication — User accounts and login
Cloud Firestore — Community contributions, saved locations, and seat reports
Xcode — Development environment

Project Goal

Nookie aims to make studying outside the home more convenient, social, and enjoyable. By combining location discovery with crowdsourced information and playful personalization, the app helps students find spaces that fit their study preferences.

Project Status

Getting Started

Clone or download this repository.
Open the .xcodeproj file in Xcode.
Configure the required Firebase project settings.
Build and run the app using an iOS simulator or compatible device.
